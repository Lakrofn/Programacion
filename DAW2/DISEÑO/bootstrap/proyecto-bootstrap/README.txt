PROYECTO EXPLORE+ — PRÁCTICA DE BOOTSTRAP 5

Abre index.html en el navegador. Se requiere conexión a Internet para cargar Bootstrap desde CDN y las imágenes de demostración desde picsum.photos.

Páginas: index.html, galeria.html, tabla.html, contacto.html.
Personalización: css/estilos.css, variables de color en :root.
El navbar y footer son iguales en los cuatro HTML, duplicados intencionadamente para no introducir plantillas ni JS propio. Si se modifica uno, hay que modificar los demás.
El formulario es solo demostrativo y no envía información a ningún servidor.
